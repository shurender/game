# Sound Effects Clips (`assets/sounds/sfx/`)

This directory houses individual SFX audio files.

---

## Standard SFX Names

| SFX Name | Audio File | Trigger Context |
| :--- | :--- | :--- |
| `menu_select` | `menu_select.wav` | Confirming menu choices or dialogues |
| `menu_move` | `menu_move.wav` | Navigating cursor in menus |
| `menu_cancel` | `menu_cancel.wav` | Canceling or closing menus |
| `attack_hit` | `attack_hit.wav` | Physical combat strike landing |
| `faint` | `faint.wav` | Creature HP reaching 0 |
| `capture_throw` | `capture_throw.wav` | Throwing a Capture Orb |
| `capture_wobble`| `capture_wobble.wav` | Capture Orb shaking on ground |
| `capture_success`| `capture_success.wav`| Capture sequence succeeding |
| `level_up` | `level_up.wav` | Creature leveling up after battle |

---

## File Format

- **Format**: Uncompressed 16-bit PCM `.wav` or 160 kbps `.ogg`.
- **Duration**: Typically 50 ms to 800 ms.
