# Overworld Character Sprites (`assets/images/sprites/`)

This directory contains standalone overworld character frames and NPC sprites.

---

## Character Specs

- **Tile Grid**: 32×32 pixel grid spacing.
- **Directional States**: 4 directions (`down`, `up`, `left`, `right`).
- **Walking Frames**: 2-frame or 4-frame walk cycles.
- **Note**: The player character sprites are loaded directly from `characters/MC/Sprites/`. Overworld NPC sprites can be placed here to replace the procedural NPC generator in `SpriteGenerator`.
