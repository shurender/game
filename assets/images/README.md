# Image Assets (`assets/images/`)

This directory contains 2D raster image assets, organized into specialized categories for tiles, creature battle sprites, overworld characters, UI icons, and spritesheets.

---

## Directory Index

| Subdirectory | Usage | Recommended Dimensions |
| :--- | :--- | :--- |
| **`creatures/`** | Front and back battle sprites for collectible creatures. | 64×64 or 128×128 PNG (transparent background) |
| **`icons/`** | Inventory item icons, elemental type badges, status icons. | 16×16 or 24×24 PNG |
| **`sprites/`** | Overworld NPC, trainer, and character walk frames. | 32×32 or 32×40 PNG |
| **`spritesheets/`** | Compact sprite sheets for environment props and animation sets. | Variable PNG grids |
| **`tiles/`** | Ground, wall, and environmental tile imagery. | 32×32 PNG tiles |
