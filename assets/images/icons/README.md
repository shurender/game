# UI & Item Icons (`assets/images/icons/`)

This directory houses small UI iconography used in the inventory bag, creature summary screens, and combat HUDs.

---

## File Categories

- **Item Icons**: `potion.png`, `capture_orb.png`, `parcel.png`. Displayed in `InventoryState` and `ShopState`.
- **Type Badges**: `type_grass.png`, `type_fire.png`, `type_water.png`, etc.
- **Status Markers**: `status_psn.png`, `status_brn.png`, `status_par.png`, `status_slp.png`.

---

## Technical Specifications

- **Format**: 32-bit RGBA PNG.
- **Dimensions**: 16×16 px or 24×24 px.
