# Music Assets (`assets/music/`)

This directory is designated for non-looping long-form music tracks, cutscene melodies, and title theme overtures.

---

## File Specifications

- **Format**: `.ogg` (Vorbis) or `.mp3`.
- **Sample Rate**: 44,100 Hz, 16-bit stereo.
- **Engine Access**: Handled via `MusicManager.play_music()`.
